# Sorting Algorithms Visualizer

An interactive dark-mode sorting algorithms visualizer built with vanilla HTML, CSS, and JavaScript.

## Live Demo
- [Launch Sorting Visualizer](https://ikhlef-wassim.github.io/algo-visualizer-web/)

## Supported Algorithms
- **Bubble Sort** — $O(n^2)$
- **Selection Sort** — $O(n^2)$
- **Insertion Sort** — $O(n^2)$
- **Quick Sort** — $O(n \log n)$
